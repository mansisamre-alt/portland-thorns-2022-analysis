# NWSL Player Analysis – Portland Thorns 2022

A Python and Streamlit project analysing player performance for the
Portland Thorns during the 2022 NWSL season.

## Project Overview

This project uses player statistics to explore different aspects of
performance, including passing, shooting, defensive contributions,
playing time, and individual player performance.

The project presents the analysis through an interactive Streamlit
dashboard.

## Analysis

The dashboard includes:

- Passing Analysis
- Defensive Analysis
- Shooting Analysis
- Playing Time Analysis
- Individual Player Profiles

## Key Metrics

### Passing
- Total passes
- Successful passes
- Pass completion percentage
- Passing performance by position

### Defensive
- Tackles won
- Interceptions
- Clearances
- Blocks
- Defensive score

### Shooting
- Total shots
- Shots on target
- Shot accuracy
- Goals
- Shot conversion rate
- Goals per 90 minutes

### Playing Time
- Minutes played
- Appearances
- Starts
- Substitutions on
- Substitutions off

### Player Profiles

The dashboard allows users to select an individual player and view
their:

- Playing time
- Attacking statistics
- Passing statistics
- Defensive statistics
- Overall player summary
